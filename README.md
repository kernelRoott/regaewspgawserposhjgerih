# Telegram бот-предложка

Бот для приема предложений публикаций в канал с mini-app панелью администратора.

## Возможности

### Для пользователей:
- Отправка публикаций (фото, видео, текст, и др.)
- Проверка статуса публикации по номеру
- Кулдаун между отправками (настраивается)
- Уведомления об одобрении/отклонении

### Для администратора:
- Mini-app с черно-красным дизайном
- Просмотр постов (на рассмотрении, принятые, отклоненные)
- Одобрение/отклонение публикаций
- Статистика с графиками
- Топ пользователей
- Настройки кулдауна и текстов сообщений

## Установка

1. Установите Python 3.8 или выше

2. Установите зависимости:
```bash
pip install -r requirements.txt
```

3. Создайте файл `.env` из примера:
```bash
cp .env.example .env
```

4. Заполните `.env`:
```env
BOT_TOKEN=ваш_токен_от_BotFather
ADMIN_ID=ваш_telegram_id
WEBAPP_URL=https://ваш-домен.com
WEB_PORT=8080
```

### Как получить необходимые данные:

**BOT_TOKEN:**
1. Откройте @BotFather в Telegram
2. Отправьте команду `/newbot`
3. Следуйте инструкциям
4. Скопируйте полученный токен

**ADMIN_ID:**
1. Откройте @userinfobot в Telegram
2. Отправьте любое сообщение
3. Скопируйте ваш ID

**WEBAPP_URL:**
- Укажите домен, который предоставил ваш хостинг
- Например: `https://your-app.herokuapp.com`
- При локальном тестировании: `http://localhost:8080`

## Настройка Mini-App в BotFather

1. Откройте @BotFather
2. Выберите вашего бота командой `/mybots`
3. Нажмите `Bot Settings` → `Menu Button` → `Configure Menu Button`
4. Отправьте URL вашего mini-app (значение из `WEBAPP_URL`)
5. Отправьте название кнопки, например: "Панель"

## Запуск

```bash
python run.py
```

Бот запустится вместе с веб-сервером для mini-app.

## Использование

### Команды для пользователей:
- `/start` - Начало работы с ботом
- `/check #номер` - Проверить статус публикации

### Для администратора:
1. Откройте бота в Telegram
2. Нажмите на кнопку меню (внизу слева)
3. Откроется mini-app с панелью управления

## Структура проекта

```
bot/
├── bot.py              # Основной код бота
├── webapp.py           # Веб-сервер для mini-app
├── webapp.html         # Интерфейс mini-app
├── config.py           # Конфигурация
├── data.py             # Работа с данными (JSON)
├── run.py              # Скрипт запуска
├── requirements.txt    # Зависимости
├── .env.example        # Пример конфигурации
├── data.json           # База данных (создается автоматически)
└── settings.json       # Настройки (создается автоматически)
```

## Хранение данных

Все данные хранятся в JSON файлах:
- `data.json` - пользователи, публикации, статистика
- `settings.json` - настройки бота (кулдаун, тексты сообщений)

Базы данных не требуются - все работает "из коробки".

## Развертывание на хостинге

### Heroku:

1. Создайте `Procfile`:
```
web: python run.py
```

2. Убедитесь, что `WEB_PORT` установлен правильно (Heroku использует переменную окружения `PORT`)

3. Разверните приложение:
```bash
git init
heroku create
git add .
git commit -m "Initial commit"
git push heroku main
heroku config:set BOT_TOKEN=ваш_токен
heroku config:set ADMIN_ID=ваш_id
heroku config:set WEBAPP_URL=https://ваше-приложение.herokuapp.com
```

### VPS/Dedicated сервер:

1. Клонируйте репозиторий
2. Установите зависимости
3. Настройте `.env`
4. Запустите через systemd или screen:

```bash
screen -S bot
python run.py
# Ctrl+A, D для отсоединения
```

## Возможные проблемы

**Бот не отвечает:**
- Проверьте правильность токена в `.env`
- Убедитесь, что бот запущен

**Mini-app не открывается:**
- Проверьте `WEBAPP_URL` в `.env`
- Убедитесь, что веб-сервер запущен и доступен
- Проверьте настройку Menu Button в BotFather

**Ошибки с файлами:**
- Убедитесь, что у бота есть права на запись в папку проекта
